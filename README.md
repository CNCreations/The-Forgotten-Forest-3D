# The Forgotten Forest – 3D — Self-Contained WebGL Build

This version uses raw WebGL only. It has **no external JavaScript libraries, CDN, image, or font dependency**.

## Controls
Desktop:
- WASD / Arrow keys = move
- Shift = sprint
- E = interact / gather / attack
- Mouse drag = rotate camera

Mobile:
- On-screen D-pad = move
- LOOK buttons = rotate
- ACTION = interact / attack

## Included playable systems
- Self-contained WebGL 3D-style forest world
- Third-person camera
- Procedurally generated trees/rocks/ground
- Day/night lighting
- Fog/atmosphere
- Resource gathering
- Health, hunger, thirst, stamina
- Inventory
- Campfire
- Wildlife enemies
- Simple combat
- Exploration/day progression
- Local save
- Mobile controls
- Native Web Share API when available
- PWA manifest + service worker
- Loading timeout/error screen

## Scope
This is the corrected **first playable foundation build**, not the final commercial/Play Store release. Ads, IAP, analytics, signed Android AAB/APK and final store/legal configuration will be added later.
