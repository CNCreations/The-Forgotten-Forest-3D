# The Forgotten Forest — 3D
## Final Playable Foundation • GitHub Pages • No external libraries

A lightweight third-person 3D survival-adventure made with raw WebGL + JavaScript.
No Three.js, CDN, external images, fonts, or runtime downloads are required.

### GitHub Pages
Upload the contents of this ZIP to a repository, then enable GitHub Pages.
Open:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/game/`

### Controls
Desktop:
- WASD / Arrow keys — move
- Shift — sprint
- E — interact / gather / attack
- Mouse drag — rotate camera

Mobile:
- Left pad — move
- Look buttons — rotate camera
- ACTION — gather / attack / campfire

### Gameplay
- Third-person humanoid player
- Follow camera with smooth rotation
- Procedural forest decoration
- Resource gathering
- Wildlife enemies
- Simple melee combat
- Health, hunger, thirst, stamina
- Campfire recovery
- Day/night cycle
- Exploration days
- Local save
- Native system Share when supported
- Mobile responsive UI
- PWA manifest/service worker

### Important
This is a complete browser-playable foundation, not an AAA game and not yet a commercial Play Store release.
Production AdMob/IAP/analytics, signed Android AAB/APK, store listing assets, and final business/legal information are intentionally separate later steps.
