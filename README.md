# The Forgotten Forest – 3D
3D survival-adventure foundation build for GitHub Pages.

## Play
Upload the project to GitHub and enable GitHub Pages. Open `/game/`.
For local testing, use a modern browser or a local static server.

## Controls
Desktop: WASD/Arrows, Shift = sprint, E = interact, mouse drag = camera.
Mobile: on-screen movement, look and ACTION controls.

## Included
- Browser 3D scene using Three.js
- Third-person player + follow camera
- Procedural forest decoration
- Day/night + fog + lighting
- Wood, stone, berries and water gathering
- Health, hunger, thirst, stamina
- Inventory and local save
- Campfire
- Wildlife enemies and simple interaction/combat
- Exploration progression
- Mobile responsive controls
- PWA manifest/service worker
- Native Share when supported

## Current build
This is the first playable foundation, not the final commercial/Play Store build. Production ads, IAP, analytics, signed Android package, final legal/business data and store assets are intentionally not included yet.

Note: the first build loads Three.js from a CDN. It is therefore not fully offline/self-contained until the library is vendored locally in a later packaging pass.
